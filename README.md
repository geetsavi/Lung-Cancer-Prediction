# Lung-Cancer-Prediction
Machine Learning project for Lung Cancer Prediction using Kaggle dataset

## Overview
This project uses Machine Learning techniques to predict the likelihood of lung cancer based on patient health and lifestyle factors.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

- ## Workflow
1. Data Preprocessing
2. Exploratory Data Analysis
3. Feature Engineering
4. Model Training
5. Model Evaluation

## Results
The model was trained and evaluated to predict lung cancer risk based on input features.
